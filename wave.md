# CHALLENGE PRD: The Immersive Wave Experience

## 1. Project Context

**The Goal** : Concevoir et développer une expérience digitale premium pour **Wave** ([wave.com/fr](https://www.wave.com/fr)), qui dépasse le cadre d’un site fintech classique. Le projet doit être perçu comme une **vitrine immersive** de la marque, démontrant innovation, fluidité et maîtrise technique. Objectif : atteindre un niveau de qualité comparable aux standards **Awwwards**, avec une intégration parfaite entre performance et expérience utilisateur.

## 2. Mandatory Technical Stack (The Power Suite)

### Core Framework & Logic

- **Framework** : Next.js 15 (App Router)
- **Library** : React 19
- **Language** : TypeScript

### Styling & Aesthetics

- **Main Styling** : Tailwind CSS v4 (CSS-first approach)
- **Advanced Styling** : SCSS (pour tokens complexes et animations précises)

### Motion & Immersive Engine

- **Smooth Scrolling** : Lenis (scroll fluide et premium)
- **UI Animations** : Framer Motion (springs organiques, états de composants)
- **Complex Orchestration** : GSAP / GreenSock (ScrollTrigger, timelines avancées)
- **WebGL/3D** : Three.js / React Three Fiber (éléments spatiaux, effets immersifs haute performance)

## 3. Global Constraints

- **Performance** : 60 FPS constants, optimisé mobile-first.
- **Unicité** : aucun framework UI générique (pas de Shadcn, Material UI, Bootstrap). Chaque élément doit être **custom**.
- **UX** : transitions fluides et intuitives, sans rupture entre interaction et motion.
- **Standard** : l’expérience doit provoquer un **“Wow effect”** dès le premier chargement et démontrer une maîtrise supérieure du frontend immersif.
